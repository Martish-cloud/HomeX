# HomeX - "Find a Better Tomorrow"

> **Trusted properties. Brighter futures.**

HomeX is a flagship, production-ready luxury real estate platform built with modern architectural design principles, micro-interactions, and a comprehensive property discovery and transaction suite.

## 🚀 Core Features Beyond the Homepage

1. **Property Discovery Engine (`/properties`)**:
   - Live filtering by Metropolitan Hub (Bengaluru, Mumbai, Delhi NCR, Hyderabad, Pune, Chennai), Property Type, BHK Bedrooms, Possession Status, and Price Range.
   - Grid View vs. List View toggle.
   - Real-time sorting (Most Popular, Price: Low to High, Price: High to Low, Highest Rated).
2. **Interactive Property Details Modal**:
   - Multi-photo gallery carousel and thumbnail lightbox.
   - Verified RERA badge and specifications (Carpet Area, Super Built-up, Facing, Floor level, Balconies, Furnishing, Age).
   - Architectural highlights and verified amenities list.
   - Built-in Home Loan & EMI Estimator with dynamic sliders.
   - Assigned Verified Advisor profile with direct messaging and site visit booking.
3. **Interactive "List Property" Multi-Step Flow**:
   - 3-step wizard (Basic Info -> Specs & Pricing -> Contact Details).
   - Instant listing reference ID generation with celebratory confetti feedback.
4. **Saved Properties / Shortlist (`/saved`)**:
   - Persistent `localStorage` state with animated heart toggle.
   - Slide-over drawer and dedicated review page.
5. **Flagship Projects Showcase (`/projects`)**:
   - Township developments from India's premier developers (Sobha, Prestige, Godrej, DLF).
   - Instant digital brochure download simulation and floor plan previews.
6. **Verified Advisors Directory (`/agents`)**:
   - RERA credentials, experience years, transaction counts, and contact modals.
7. **HomeX Real Estate Journal (`/blog`)**:
   - Curated articles across Market Insights, Buying, Investment, and Lifestyle with an in-app reading modal.
8. **Financial Planning & EMI Calculator**:
   - Live interactive loan calculator with visual principal-to-interest breakdown.

## 🛠️ Technology Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Static Site Generation, SSR)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Micro-Interactions & Motion**: [Framer Motion](https://www.framer.com/motion/)
- **Celebrations**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Typography**: Plus Jakarta Sans & Caveat Google Fonts

## 💻 Getting Started

### Prerequisites
- Node.js 18+ or 20+
- npm 9+ or 10+

### Installation & Run
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

Visit [http://localhost:3000](http://localhost:3000) to view HomeX.
